# 见山 · 视觉设计规范（学生端）

用途：在修改「见山」学生端任何界面/样式前，先按本规范逐项对齐。目标是还原一套
「温柔、安静、治愈、自然」的校园心理关怀视觉，而不是传统后台/科技风。

## 0. 审美总原则（最重要）

- 温柔、安静、治愈、自然；大面积留白，**呼吸感**优先于信息密度。
- 不拥挤、不堆叠；宁可多留白，不要塞满。
- **禁止**：高饱和色、复杂渐变、科技感发光、厚重阴影、商务后台风、AI 生成感
  （过度圆润的"果冻"卡片、千篇一律的 emoji 堆砌、无意义的装饰线）。
- 插画走**简约手绘线稿 + 柔和色块**（水彩感），线条统一细、颜色统一克制。
- 交互**轻柔克制**：悬停仅轻微上浮（约 2px）或轻微变色，动画短而柔（≤240ms）。
- 图标统一细线条，大小/颜色/线宽一致。
- 正文字色永远用深色（正文 #3A3A38），主色只做底色/边框/强调，**不做正文**。

## 1. 色彩体系

| 语义 | 色值 | 用途 |
|---|---|---|
| 页面主背景 | `#F7F6F1` | 温暖米白 |
| 卡片背景 | `#FFFFFF` | 干净暖白 |
| 选中状态 | `#DCE9DF` | 浅灰绿（导航选中、卡片色调之一） |
| 品牌主色 | `#355B4C` | 低饱和墨绿（Logo、选中文字、圆箭头按钮、插画描边） |
| 辅助色 A | `#E5EEF2` | 浅雾蓝 |
| 辅助色 B | `#F4E5D6` | 暖杏 |
| 卡片边框 | `#E9E7DF` | 1px 细边框 |
| 侧边栏底色 | `#F3F1E9` | 浅米白 |
| 正文 / 次要 / 弱化 | `#3A3A38` / `#6E6A63` / `#9A948A` | 三级文字 |
| 错误提示 | `#C9836B` | 柔化红（非刺眼红，仍是深色字） |

- 四张功能卡片各自独立柔和底色：问卷=雾蓝 `#E5EEF2`、树洞=暖杏 `#F4E5D6`、
  预约=浅灰绿 `#DCE9DF`、我的档案=暖米 `#F0EDE4`。
- 正文对比度 ≥ 4.5:1（WCAG）。

## 2. 字体层级

| 元素 | 字号 | 字重 |
|---|---|---|
| 品牌名称 | 24px | 半粗(600) |
| 页面主标题 | 30px | 半粗(600) |
| 区域标题 | 20px | 半粗(600) |
| 卡片标题 | 18px | 中等(500) |
| 正文 | 14px | 常规(400) |
| 辅助说明 | 12px | 常规(400) |
| 状态标签 | 12px | 中等(500) |

- 中文优先「微软雅黑 / 思源黑体」；标题可用适度衬线字体点缀；**缺字体不得崩溃**
  （回退到系统 sans-serif）。

## 3. 窗口与布局

- 基准窗口 1440×900，最小 1100×700。
- 左侧导航固定宽 220px，不随内容滚动。
- 主内容区自适应，内边距 32px；卡片间距 20px。
- **页面滚动只作用于右侧内容区**。
- 窄窗口：四张核心卡片自动两列、辅助区上下排列，**禁止横向溢出**。

## 4. 卡片规范

- 标准圆角 16px，小圆角 12px；边框 1px `#E9E7DF`；内边距 20px。
- 背景纯白或低饱和浅色；**不用明显投影**。
- 悬停：轻微颜色变化或上移 2px，动画短柔。

## 5. 首页结构（自上而下）

1. **顶部欢迎区**：左「你好，{姓名}」+ 副标题「今天的你，也在努力发光。」；右山峦插画（太阳/云朵/飞鸟/山）。
2. **核心功能区**：问卷 / 树洞 / 预约 / 我的档案 四张卡片横排，插画在上、标题+描述在下、右下圆箭头。
3. **内容辅助区**：「今日的小纸条」（暖白纸张、手写信纸感、右下植物/胶带小插画，含「换一条」+ 署名「—— 见山」）
   与「最近活动」并列；小纸条文案从配置读取，不硬编码、不说教、不与心理状态强行关联。
4. **底部提示区**：「慢慢来，也算在前进。」+ 极简山峰线稿。
5. **左侧导航**：品牌（山峰 Logo + 见山 + 标语「在这里，遇见更好的自己」）→
   功能菜单（首页/问卷/树洞/我的档案/预约）→ 底部（设置/关于 + 头像/班级/姓名）。

## 6. 代码映射（当前实现）

- 主题常量与 QSS：`desktop_common/theme.py`
  （`BG/CARD/LINE/BRAND/BRAND_SELECTED/AUX_MIST/AUX_APRICOT/NAV_*`）。
- 首页组件：`student_desktop/student_desktop/ui/home.py`
  （`HomePage`、`_SvgArt`、`svg_pixmap`）。
- 插画资源：`student_desktop/student_desktop/assets/*.svg`（本地 SVG，QSvgRenderer 渲染）。
- 卡片配色用动态属性 `tone` + QSS `QFrame#HomeFeatureCard[tone="..."]`，**不写内联样式**。
- 所有中文文案集中管理：`COPY["home.*"]`（`desktop_common/copy_text.py`），UI 不硬编码中文。
- 窗口尺寸 / 侧边栏三区结构 / 首页接线：`student_desktop/student_desktop/app/main.py`。

## 7. 审美检查清单（改完逐项自检）

1. 正文对比度 ≥ 4.5:1，主色没被当正文字色。
2. 无内联 `setStyleSheet`（统一走 theme.py 的 objectName/动态属性 QSS）。
3. 圆角、间距、字号、线宽全局一致。
4. 无硬编码中文（全部 `COPY["..."]`）。
5. 插画风格统一（同一套 SVG 资源，线稿+柔和色块）。
6. 留白充分，页面不拥挤。
7. 悬停/选中反馈克制（轻微上浮或变色，≤240ms，无弹跳/闪烁/循环动画）。
8. 窄窗口不横向溢出（四卡自动两列）。
9. 不改业务逻辑/接口/数据库；只为视觉服务。
10. 改完跑 `python -m student_desktop.app.selfcheck --skip-network` 确认 104 项全绿，
    再离屏渲染 `home` 截图核验（程序化采样背景/卡片/墨绿/暖阳是否出现、非空白）。
